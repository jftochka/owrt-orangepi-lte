## Delivered

The OrangePi Zero3 runs OpenWrt 25.12.1 with a Quectel EG25-G and a Kigen eUICC.
`simei` provides a shell TUI and CLI for SIM profiles, IMEI assignment and reassignment,
eSIM management through `lpac`, status, and a live dashboard. `switch` enables an
eSIM profile and applies its assigned IMEI; `apply` writes, restarts, and verifies.
All-zero IMEIs are rejected and are not saved as factory backups.

The recorded installation includes LuCI, QMI networking, modem/SMS pages, ttyd web
terminals, a socat AT bridge, and Tailscale SSH. Bring-up scripts, fake modem/eSIM
tests, a [README](../README.md), and the [StrictDoc user guide PDF](simei-user-guide.pdf)
are committed. User-guide source is [simei-user-guide.sdoc](simei-user-guide.sdoc).

## Maintenance context

The main program is `simei/usr/sbin/simei`; services, hotplug, UCI defaults, and LuCI
assets are under `simei/`. Host tools are under `tools/`. Use socat for serial and AT
access, `python3` for Python work, and append every project shell command to
`claudehistoryfile.txt`. Behavior changes need tests and a descriptive git commit.
Maintain the user guide in StrictDoc and export its PDF when updating it.

The documented host test commands are `sh simei/tests/run.sh` and
`TEST_SH=dash sh simei/tests/run.sh`. The installed router suite is
`sh /usr/lib/simei/tests/run.sh`; it exercises the installed program with fakes.

A full `tools/rt push simei /` also overwrites `/etc/config/simei`, so preserve live
profiles before a future deployment. It copies the test directory to `/tests`;
`tools/03-configure.sh` relocates that directory to `/usr/lib/simei/tests`.
A plain push alone therefore does not refresh the installed test suite. The
configuration script also changes network and service settings; it is a bring-up
operation, not a status check.
